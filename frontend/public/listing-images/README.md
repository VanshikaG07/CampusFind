# CampusFind — Listing Images

Welcome to your listing images directory! You can drop any photos here for your campus listings.

## 📁 How It Works
- Whenever a resource in `src/data/resources.js` specifies an image, it looks in this folder.
- Supported image formats: **`.jpg`**, **`.jpeg`**, **`.png`**, **`.webp`**, **`.svg`**.

## 💡 How to Add Your Own Custom Photos
1. Copy your picture (e.g., `my-cycle.jpg` or `lab-coat.png`) into this folder (`public/listing-images/`).
2. When creating or editing a resource, select or set the image URL to `/listing-images/my-cycle.jpg`.
3. The image will automatically render directly in the listing cards and detail pages!
